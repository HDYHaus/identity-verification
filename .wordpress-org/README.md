# WordPress.org Assets

Copy the image files in this directory to the top-level `/assets` directory of
the WordPress.org SVN repository. They are intentionally excluded from the
installable plugin ZIP.

The icon and banner are original generated artwork prepared for TrustGate
Registration. Screenshots were captured from an isolated local WordPress 7.1.2
site using dummy provider settings. They show the native registration form,
global Registration settings, and Prembly provider settings. All files are
licensed under GPL-2.0-or-later.
